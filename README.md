# Celestical: downloads

The desktop app for [Celestical](https://celestical.app), for Mac, Windows and Linux. This repository holds only the
installers and the files the app reads to update itself. The newest is always under
[Releases](https://github.com/jamesrobertcrisp-code/Celestical-Releases/releases/latest).

| System | Download |
| --- | --- |
| Mac, Apple silicon (M1 and later) | [Celestical-mac-arm64.dmg](https://github.com/jamesrobertcrisp-code/Celestical-Releases/releases/latest/download/Celestical-mac-arm64.dmg) |
| Mac, Intel | [Celestical-mac-x64.dmg](https://github.com/jamesrobertcrisp-code/Celestical-Releases/releases/latest/download/Celestical-mac-x64.dmg) |

| Linux, AppImage | [Celestical-linux-x86_64.AppImage](https://github.com/jamesrobertcrisp-code/Celestical-Releases/releases/latest/download/Celestical-linux-x86_64.AppImage) |

## Opening it the first time

The builds are not signed with a paid certificate, so each system asks once.

- **Mac**: open the .dmg, drag Celestical to Applications, then right-click it and choose Open.
- **Windows**: on "Windows protected your PC", choose More info, then Run anyway.
- **Linux**: make the AppImage executable (`chmod +x Celestical-linux-x86_64.AppImage`) and run it, or install the .deb.

## Updates

Windows and the Linux AppImage update themselves. A Mac and a .deb install tell you when a newer version is here.

Prefer not to install anything? Celestical also runs in a browser at [app.celestical.app](https://app.celestical.app),
and can be added to a phone's home screen from there.
